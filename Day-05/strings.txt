String
String is an immutable sequence of characters that can be enclosed in either single (')or double(" ")or triple(''' ''')
example:
s='python'
s="python"
s='''python'''
Operations on strings:
concatenation(+): joining two or more strings.
Repetition(*): Repeating a string multiple times.
indexing: accessing individual elements of a sequence using their position.
slicing: Extracting a part of the string.
membership(in, not in):checking if a substring exists within a string.
Built in strings Functions:
len()
max()/min()
sorted()
chr()/Ord()
case conversion:
upper(),lower(),capitalize(),title(),swap case(),case fold()
