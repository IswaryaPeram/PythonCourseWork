Tokens in python
Tokens are smallest units of a python program
python has five types of tokens:
1 keywords-pre-define functions(if,else,for,def)
2 identifiers-names of variables,functions,and classes
3 literals-constant values (10,"hello",3.14)
4 operators-(+,-,*,/)
5 punctuators-(),{},[],:,
n=2
